# Korvex на FACTS Grounding: набор для воспроизведения

Скрипты и данные, чтобы проверить или повторить наш замер **DSR Etude 0 Preview** на **FACTS Grounding v2** — бенчмарке
Google DeepMind о том, держатся ли ответы в рамках документа. Наша статья, где рядом с нашей цифрой стоит официальная таблица:
<https://korvexai.site/articles/benchmarks/>. English version: [README.md](README.md).

## Результат

**87,2 %** ответов полностью подтверждены документом: 200 задач из публичной половины набора, оценка официальной парой судей
(Gemini 2.5 Flash и GPT-5, `gpt-5-2025-08-07`) по официальным промптам и официальному правилу подсчёта. 95 % доверительный
интервал (бутстрап по задачам, 10 000 повторов, seed 20261104): **83,0 – 91,2**. 2 ответа из 200 получили 0 за невыполнение
задачи (оба судьи нашли серьёзную проблему); судьи разошлись по обоснованности в 21 ответе из 200. Ответы получены 6–7 ноября
2026, судейство прошло 8 ноября 2026.

## Что проверяет FACTS Grounding

Модель получает документ до 32 тыс. токенов и задачу по нему. Ответ засчитывается, только если каждое предложение в нём
подтверждено документом. Ответ, не выполнивший саму задачу, получает 0 ещё до проверки фактов.

## Как мы мерили

* **Задачи.** 200 из публичной половины набора: позиции 200–399 в фиксированном случайном порядке. До прогона мы эти задачи
  не открывали. Номера их строк в официальном `examples.csv` — в [`tasks/tasks200_idx.txt`](tasks/tasks200_idx.txt).
* **Система.** DSR Etude 0 Preview, режим Max. Память — единственный инструмент: ни кода, ни веба, ни браузера. Задача
  отправляется как в официальном ноутбуке: инструкция, документ и запрос одним сообщением (колонка `full_prompt`), без
  изменений (в 3 задачах из 200 — `facts-160`, `facts-243`, `facts-319` — слишком длинные строки переносились: строки длиннее
  20 000 символов разрезаются по пробелу и продолжаются на следующей строке; `run_answers.py` делает то же самое). Один прогон.
* **Судьи: официальная пара.** Gemini 2.5 Flash через Kaggle Benchmarks, как в официальном ноутбуке FACTS. GPT-5
  (`gpt-5-2025-08-07`) через API OpenAI с настройками по умолчанию. Промпты судей и разбор их ответов взяты дословно из
  официального ноутбука FACTS Grounding v2 на Kaggle. Самого ноутбука в этом наборе нет: скрипты берут промпты и разборщики из
  копии, которую вы скачиваете сами.
* **Подсчёт: официальное правило.** Ответ получает 0 за невыполнение задачи, только если оба судьи нашли серьёзную проблему.
  Иначе оценка задачи — среднее двух судей (у каждого судьи 1, если каждое предложение подтверждено, иначе 0).
* **Что видит судья.** Текст ответа после последнего маркера `</think>`, без пробелов по краям (такой маркер был лишь в одном
  ответе из 200; обычно API отдаёт рассуждение отдельно).

## Чем наш замер отличается от официального

* **200 задач вместо 1 715.** Поэтому погрешность около ±4 пунктов против примерно ±2 у моделей в таблице. На доске публичная и
  приватная половины расходятся в среднем на 1 пункт.
* **Мы мерим систему, а не голую модель.** Kaggle сам запускает модели из таблицы. Наша работает через наш сервер; текст задачи
  тот же.
* **Режим Max.** Kaggle не публикует настройки рассуждения, с которыми гоняет модели из таблицы.
* **Один прогон.**

Если вы повторяете замер через публичный API, добавляются ещё три момента:

* **Max через API сейчас недоступен.** Уровень max временно закрыт в публичном API: для наших серверов он слишком дорогой.
  Запрос с `"reasoning_effort": "max"` получает ошибку 400 `reasoning_effort_unavailable`. Пересчёт наших опубликованных
  ответов (шаг 5) даёт 87,2 % без API. Новый прогон через API сейчас возможен на `xhigh` (`--effort xhigh`); его цифры
  с нашими (Max) не сравнимы.
* **Сервис меняется.** Опубликованные ответы получены на сервисе таким, каким он был 6–7 ноября 2026. Более поздний прогон
  измеряет ту версию, которая работает в этот момент.
* **API — не тот экземпляр, на котором мы мерили.** Мы гоняли отдельный экземпляр с включённым только инструментом памяти;
  обычный запрос к API (этот набор не передаёт инструментов) попадает на публичный сервис.

## Что в наборе

```
README.md, README.ru.md       этот файл
LICENSE                       MIT, только на скрипты
run_answers.py                ответы от API Korvex (только стандартная библиотека, с докачкой)
tasks/tasks200_idx.txt      200 номеров строк examples.csv в порядке прогона
tasks/build_tasks.py          examples.csv + список номеров -> tasks.jsonl
judge_gemini_kaggle/          судья Gemini 2.5 Flash: генератор ноутбука и пошаговая инструкция
judge_gpt5.py                 судья GPT-5 через API OpenAI с жёстким потолком расходов
score_official_pair.py        официальный подсчёт по паре судей с бутстрап-интервалом
verify_verdicts.py            заново разбирает сохранённые ответы судей официальными разборщиками (без вызовов API)
official_cells.py             загружает промпты и разборщики судей из скачанного вами официального ноутбука
results/answers.jsonl         наши 200 ответов: {id, idx, response}
results/gemini_verdicts.jsonl вердикты Gemini: {id, quality_rating, eligible, grounded, raw_quality, raw_grounding}
results/gpt5_verdicts.jsonl   вердикты GPT-5, те же поля (+ quality_called; качество GPT-5 оценивает только там, где Gemini увидела Major)
results/summary.json          вывод score_official_pair.py на этих файлах
```

Нужен Python 3.9 или новее, ставить пакеты не надо (командная строка Kaggle нужна только для шага с Gemini). Скрипты читают
ключи только из переменных окружения и никогда их не печатают.

## Быстрая проверка: пересчитать наши ответы (бесплатно, без сети)

Получится ровно **87,2** и **[83,0; 91,2]**; подсчёт детерминирован:

```bash
python3 score_official_pair.py results/gemini_verdicts.jsonl results/gpt5_verdicts.jsonl
# Score: 87.2 %   95% bootstrap CI: [83.0, 91.2]   (n=200 tasks, 2 scored 0 as ineligible)
```

Чтобы убедиться, что сохранённые вердикты действительно следуют из сырых ответов судей, скачайте официальный ноутбук (бесплатно,
нужен аккаунт Kaggle) и прогоните по ним официальные разборщики; вызовов API нет, ничего заново не оценивается:

```bash
kaggle kernels pull prathameshbang/facts-grounding-v2-benchmark-starter -p work/starter
python3 verify_verdicts.py --starter work/starter/facts-grounding-v2-benchmark-starter.ipynb \
    --gemini results/gemini_verdicts.jsonl --gpt5 results/gpt5_verdicts.jsonl
```

## Воспроизведение с нуля

Понадобятся: ключ API Korvex (`kx-...`; Max через API временно закрыт — см. выше), аккаунт Kaggle и ключ OpenAI API, которому доступна
`gpt-5-2025-08-07`. Учтите, что OpenAI указывает для этого снапшота отключение 2026-12-11
([deprecations](https://platform.openai.com/docs/deprecations)); после этой даты шаг с GPT-5 в опубликованном виде повторить
нельзя, останется только пересчёт выше.

Сколько это занимает, по нашему прогону (ориентировочно, у вас будет иначе):

| Шаг | Время | Стоимость |
|---|---|---|
| Ответы, 200 задач на Max, 2 запроса параллельно | в среднем 5,5 мин на задачу (медиана 4,5, самая долгая 29), всего около 9 часов | расходуется с вашего ключа Korvex |
| Gemini 2.5 Flash на Kaggle, 5 вызовов параллельно | 27 минут | в рамках вашей квоты на бенчмарк-модели Kaggle |
| GPT-5 через OpenAI, 4 вызова параллельно | около 30 минут | около $12 за 200 ответов (около $0,06 за задачу) |

**1. Скачайте официальные примеры** (856 строк; датасет под CC BY 4.0) и соберите файл задач:

```bash
mkdir -p work && kaggle datasets download -d deepmind/facts-grounding-examples -p work --unzip
python3 tasks/build_tasks.py --examples work/examples.csv --idx tasks/tasks200_idx.txt --out work/tasks.jsonl
```

Скрипт предупредит, если ваш `examples.csv` не побайтно совпадает с нашим (SHA-256 начинается с `66990aea`, версия датасета 17):
тогда номера строк могут указывать на другие задачи.

**2. Получите ответы через API.** Публичный адрес `https://api.korvexai.site/v1`, модель `dsr-etude-0-preview` (есть и
`dsr-etude-latest` — всегда текущая версия), OpenAI-совместимый `POST /v1/chat/completions`:

```bash
export KORVEX_API_KEY="kx-<ваш ключ>"
python3 run_answers.py --tasks work/tasks.jsonl --out work/answers.jsonl --dry-run           # покажет запрос, ничего не отправит
python3 run_answers.py --tasks work/tasks.jsonl --out work/answers.jsonl --limit 3           # сначала три задачи
python3 run_answers.py --tasks work/tasks.jsonl --out work/answers.jsonl --workers 2         # все 200; повторный запуск докачивает
```

Каждый запрос выглядит ровно так (один на задачу, без системного сообщения, без инструментов, без параметров сэмплирования):

```json
{"model": "dsr-etude-0-preview", "stream": false, "reasoning_effort": "max",
 "messages": [{"role": "user", "content": "<full_prompt задачи>"}]}
```

с заголовками `Authorization: Bearer $KORVEX_API_KEY` и `Content-Type: application/json`. Заголовок беседы не передаётся, так
что каждая задача — независимый разовый запрос. У ключа есть лимит запросов в минуту и лимит параллельных запросов; при ответах
429 уменьшите `--workers` (скрипт и сам повторяет запрос).

**3. Судейство Gemini 2.5 Flash на Kaggle.** Следуйте [judge_gemini_kaggle/README.md](judge_gemini_kaggle/README.md) (на
английском). Результат — `work/gemini_out/gemini25flash_judged.jsonl`.

**4. Судейство GPT-5 через OpenAI.** Промпты берутся из скачанного вами официального ноутбука. `--budget-usd` — жёсткий потолок
расходов (новый вызов не начнётся, когда потолок достигнут; сначала запустите с `--dry-run`):

```bash
export OPENAI_API_KEY="sk-<ваш ключ>"
python3 judge_gpt5.py --tasks work/tasks.jsonl --answers work/answers.jsonl \
    --gemini work/gemini_out/gemini25flash_judged.jsonl \
    --starter work/starter/facts-grounding-v2-benchmark-starter.ipynb \
    --out work/gpt5_verdicts.jsonl --budget-usd 20 --dry-run
```

Уберите `--dry-run`, чтобы запустить судейство. Как и в официальном ноутбуке, GPT-5 оценивает выполнение инструкции только для
ответов, где Gemini нашла серьёзную проблему, а обоснованность проверяет для каждого ответа. Параметры API — по умолчанию
(только `model` и `messages`).

**5. Подсчёт:**

```bash
python3 score_official_pair.py work/gemini_out/gemini25flash_judged.jsonl work/gpt5_verdicts.jsonl
```

## Чего ожидать

* **Пересчёт наших файлов** даёт ровно 87,2 [83,0; 91,2].
* **Повторное судейство наших ответов** даст не в точности те же вердикты: вызовы судей недетерминированы, несколько пограничных
  предложений меняют оценку. Ждите результат рядом с нашим, но не идентичный.
* **Новый прогон ответов** тоже не воспроизведёт 87,2: ответы от прогона к прогону различаются. На 200 задачах у одного прогона
  погрешность около ±4 пунктов, так что новый прогон должен лечь близко к нашему интервалу 83,0–91,2 (немного за его пределами —
  возможно просто случайно, и сдвинуть результат может изменившаяся версия сервиса).

## Ограничения этого свидетельства

200 задач публичной половины, а не полные 1 715; один прогон; система, замеренная через наш собственный сервер, а не голая
модель; режим Max, при том что настройки моделей на доске не опубликованы; сами официальные судьи несовершенны (в 21 ответе из
200 они разошлись по обоснованности: в 14 случаях Gemini сочла ответ обоснованным, а GPT-5 нет, в 7 — наоборот). Нашей системы
нет в таблице Kaggle, и Kaggle её не запускал.
